# App Salão

Este projeto é um exemplo simples de app Flutter para agendamento de horários em um salão de cabelo em Barcelona. Os usuários podem criar conta, fazer login, escolher o barbeiro preferido, selecionar data e horário e confirmar o agendamento. Há um botão de pagamento ilustrativo, mas o processamento real não está implementado.

## Estrutura
- `pubspec.yaml` define as dependências do Flutter.
- `lib/` contém o código Dart com telas de login, cadastro e agendamento.

## Como executar
1. Instale o Flutter em sua máquina.
2. Dentro do diretório do projeto, execute `flutter pub get` para baixar as dependências.
3. Execute `flutter run` para iniciar o aplicativo em um dispositivo ou emulador.

Este código serve apenas como ponto de partida e precisa de integração com backend para autenticação real, envio de e-mails e pagamentos.
