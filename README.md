# App Salão

Aplicativo Flutter para agendamento de horários em um salão de cabelo em Barcelona.

## Requisitos
- Flutter e Dart instalados
- Configurar um projeto Firebase (Auth, Firestore)
- Configurar métodos de pagamento (ex. Stripe)

## Como rodar

1. Instale as dependências:
   ```bash
   flutter pub get
   ```
2. Execute o app:
   ```bash
   flutter run
   ```

## Estrutura
- `lib/main.dart` contém a implementação básica de autenticação por email, listagem de barbeiros e tela de agendamento.
- `pubspec.yaml` lista as dependências principais do projeto.

Este é apenas um esqueleto inicial e precisa ser configurado com seu projeto Firebase e chaves de pagamento.
